# 角色包（皮肤）制作教程

把一个文件夹丢进皮肤目录，桌宠就能变成**你自己的角色**：立绘、声音、聊天人设、台词都可以换。
没画的状态、没录的台词会自动用内置的哈基米顶上，所以**画两三张图就能玩**，慢慢补全。

---

## 1. 五分钟上手

### 方式一：直接拖入 `.zip` 角色包（最简单）
1. 拿到别人分享的 `xxx.zip` 角色压缩包后，**直接用鼠标把 `.zip` 拖到桌面上的哈基米身上松手**（或者右键桌宠 →「👗 换装」→「🎭 角色」→「📦 导入角色包 (.zip)…▪」）。
2. 程序会自动做安全体检（拦截 `..` 路径穿越、超体积压缩炸弹和任何可执行/脚本文件，校验 `skin.json` 与 PNG 图片头），解压进 `skins\<id>\` 并立即变身，同时在气泡里汇报立绘与语音数量。

### 方式二：手动放文件夹（适合边画边调）
1. 右键桌宠 →「👗 换装」→「🎭 角色」→「📂 打开皮肤文件夹」（即 `%APPDATA%\hakimi-pet\skins\`）。
2. 把仓库里的示例 `examples/skins/demo` 整个文件夹复制进去：
   ```
   %APPDATA%\hakimi-pet\skins\demo\skin.json
   %APPDATA%\hakimi-pet\skins\demo\idle.png
   ...
   ```
3. 右键 →「👗 换装」→「🎭 角色」→「🔄 刷新皮肤列表」，再点「薄荷哈基米（示例）」。
4. 示例只画了 待机/开心/睡觉/思考 4 个状态；其余没画的表情默认会**回退到角色自己的 `idle` 待机图**（不会突然闪回原版哈基米；如果你做的是哈基米换色皮肤，可在 `skin.json` 写 `"fallback": "builtin"` 让缺失表情借用原装哈基米）。
5. 想换回来：「🎭 角色」→「🐱 哈基米（内置）」。

当前用的是哪个角色记在 `save.json` 的 `skin` 字段里，重启后保持。
每个自定义角色还拥有**独立的长期记忆与聊天历史目录**（`%APPDATA%\hakimi-pet\skins-data\<id>\` 下的 `memory.json`、`chat.json`、`chat-log.jsonl`）：切换角色不会串记忆，把 `skins\<id>` 打包分享给朋友时也不会误把私人记忆带出去。

## 2. 文件夹结构

```
skins\
  我的角色\              ← 文件夹名就是角色 id（可以用中文，别叫 hakimi，别以 @ 或 . 开头）
    skin.json            ← 必须有
    idle.png             ← 图片随便放、随便起名，在 skin.json 里写对就行
    表情\开心.png         ← 可以有子文件夹（路径用 / 或 \ 都行）
    blink.png            ← 叠加层（可选）
    voice\               ← 语音（可选）
```

## 3. skin.json 字段

```json
{
  "formatVersion": 1,
  "id": "mint_cat",
  "name": "薄荷哈基米",
  "author": "你的名字",
  "version": "1.0",
  "persona": "你是「薄荷」，……（会追加到 AI 聊天的系统提示词末尾）",
  "scale": 1.0,
  "fallback": "idle",
  "sprites": {
    "idle": "idle.png",
    "happy": "表情/开心.png"
  },
  "overlays": {
    "blink": "blink.png",
    "mouthOpen": "mouth.png"
  },
  "voiceDir": "voice",
  "tts": {
    "mode": "preset",
    "voice": "蜜桃",
    "style": "清冷温柔的少女音，说话轻柔自然",
    "refAudio": "voice/ref.mp3",
    "sovitsPrompt": "参考音频里对应的那句台词"
  },
  "lines": {
    "poke": ["戳我干嘛喵？", "嗯？"],
    "哈基米上线啦喵～": "薄荷上线啦！"
  }
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `formatVersion` | 否 | 清单规范版本号，当前填 `1` |
| `id` | 否 | 角色唯一英文/中文目录名（导入平铺 `.zip` 时优先按此建文件夹；不能叫 `hakimi`） |
| `name` | 否 | 菜单里显示的名字；不写就用文件夹名 |
| `author` / `version` | 否 | 显示在菜单名字后面 / 给你自己看 |
| `persona` | 否 | 聊天人设，**追加**在内置提示词后面，并声明优先级高于内置的外形和自称。最多 2000 字 |
| `scale` | 否 | 立绘大小倍数（0.2–2.0），不写 = 自动缩放，见第 4 节 |
| `fallback` | 否 | 缺失表情的回退策略：默认 `"idle"`（用你自己的 `idle` 图兜底，不闪回哈基米）；填 `"builtin"` 则回退内置哈基米 |
| `sprites` | 否 | 状态名 → 图片文件，共 32 个标准表情状态，见第 5 节 |
| `overlays` | 否 | 叠加层：`blink`（闭眼）、`mouthOpen`（张嘴），见第 6 节 |
| `voiceDir` | 否 | 固定台词录音文件夹，见第 7 节 |
| `tts` | 否 | 角色专属在线/本地 TTS 声线覆盖（`mode` 支持 `clone` / `preset` / `design` / `sovits`；`refAudio` 只能指向包内音频文件，不允许配置外部服务器地址） |
| `lines` | 否 | 换台词，见第 8 节 |

解析很宽松：缺字段就当没写；某个字段写错类型（比如 `"scale": "大"`）只忽略这一个字段；
**整个文件不是合法 JSON** 的话这个角色包会被跳过，菜单里会提示「N 个角色包读不了」，原因写在
`%APPDATA%\hakimi-pet\hakimi.log`。写完可以先拿 VS Code / 任意 JSON 校验网站检查一下。
注意 JSON 里不能有注释、最后一项后面不能有逗号；文件存成 UTF-8。

## 4. 图片尺寸建议

- 只支持 **PNG**（带透明通道）。单张不超过 16MB、边长不超过 4096。
- 内置立绘是 **400×587**（宽:高 ≈ 0.68），显示在 200×293 的框里，高 DPI 屏会放大到 1.5–2 倍。
  **推荐就画 400×587 或 600×880**，角色脚底贴着画布底边，左右居中，四周透明。
- 尺寸不一样也没关系：程序会**等比缩放**塞进框里，**贴底、水平居中**。
  如果你的图四周留白很多，角色会显得小，用 `"scale": 1.2` 放大；太挤就 `0.9`。超出框的部分会被裁掉。
- 所有状态图最好**同一尺寸、同一位置**画，切换表情时角色才不会跳。
- 图片按需加载：只有当前角色、当前用到的那张才会解码并缩小，换角色时旧图立刻释放，不会多吃内存。

## 5. 状态列表（共 32 个标准表情）

状态名和 `assets/sprites` 里的文件名一致（全小写）：

| 状态 | 什么时候出现 | 没画时（默认 `"fallback": "idle"`） |
|---|---|---|
| `idle` | 待机、发呆底图 | 哈基米 |
| `blink` | 待机时眨眼（一闪 0.14 秒） | 用你的 `idle`（有 `blink` 叠加层就盖上去） |
| `walk1` `walk2` | 走路时交替的两帧 | 互相借，再不行用你的 `idle` |
| `happy` | 开心、打招呼、换装 | 你的 `idle` |
| `think` | 发呆思考、聊天等回复 | 你的 `idle` |
| `sit` | 坐下 | 你的 `idle` |
| `sleep` | 睡觉 | 你的 `idle` |
| `sleepy` | 犯困点头打盹 | 你的 `idle` |
| `yawn` | 打哈欠 | 你的 `idle` |
| `eat` | 吃东西 | 你的 `idle` |
| `hungry` | 饿了讨食 | 你的 `idle` |
| `drool` | 馋得流口水 | 你的 `idle` |
| `drag` | 被鼠标拎起来、掉落 | 你的 `idle` |
| `shy` | 被摸头害羞 | 你的 `idle` |
| `wink` | 俏皮眨单眼放电 | 你的 `idle` |
| `love` | 比心、亲密度升级 | 你的 `idle` |
| `starry` | 星星眼崇拜/任务完成 | 你的 `idle` |
| `cheer` | 举爪加油打气 | 你的 `idle` |
| `smug` | 得意叉腰显摆 | 你的 `idle` |
| `pout` | 鼓嘴撒娇小委屈 | 你的 `idle` |
| `puff` | 气鼓鼓生闷气 | 你的 `idle` |
| `surprised` | 被吓一跳 | 你的 `idle` |
| `confused` | 歪头疑惑冒问号 | 你的 `idle` |
| `sweat` | 尴尬流汗吐槽 | 你的 `idle` |
| `scared` | 害怕发抖/报错提醒 | 你的 `idle` |
| `cry` | 心情很差时哭 | 你的 `idle` |
| `hiss` | 被连戳生气哈气 | 你的 `idle` |
| `dizzy` | 被甩晕 | 你的 `idle` |
| `stare` | 盯着你看 | 你的 `idle` |
| `dance` | 跳舞、放歌 | 你的 `idle` |
| `honey` | 喝蜂蜜水 | 你的 `idle` |

建议优先画：`idle`（强烈建议必画） → `happy` → `sleep` → `drag` → `think` → `shy` → `wink` → `pout`。

用了你自己的图时，哈基米专属的东西（会摆的尾巴、头顶的星星、圆眼镜配件）不会画上去，
因为它们的位置是按哈基米对齐的。整套衣服（女仆装等）也是哈基米专属，换角色后只在回退的状态里看得到。

## 6. 叠加层怎么对齐

叠加层是一张**和立绘一模一样大**的透明 PNG，只在要变的地方有像素（比如闭着的眼睛），其余全透明。
程序用和立绘完全相同的缩放和位置把它盖上去，所以：

1. 在绘图软件里打开 `idle.png`，**新建图层**；
2. 在新图层上画闭眼（盖住原来的眼睛，必要时先用肤色把睁眼涂掉）；
3. 隐藏原图层，**画布尺寸不要改、不要裁剪**，导出新图层为 `blink.png`。

- `blink`：没有 `blink` 立绘时，眨眼 = `idle` + `blink` 叠加层。示例里的 `blink.png` 就是这样做的。
- `mouthOpen`：说话张嘴用的，接口已经留好（`render::skin_loader::overlay`），等「呼吸/眨眼/张嘴」那条线接上就生效，
  做法同上。

## 7. 语音

在 `voiceDir` 指的文件夹里放台词语音，**文件名规则和内置台词一样**：台词文本的 SHA-1 取前 16 位十六进制。
另外也可以直接**用台词当文件名**，省得算哈希。

| 台词 | 文件名（两种都行） |
|---|---|
| 喵？找哈基米有事吗～ | `2b60dc85bb8a2964.ogg` 或 `喵？找哈基米有事吗～.ogg` |

- 格式：`.ogg`（Vorbis）、`.wav`、`.mp3`、`.flac`。Opus 编码的 ogg 目前放不出来，会被跳过。单个文件 ≤ 8MB。
- Windows 文件名不能有的 `\ / : * ? " < > |` 换成 `_`（注意中文全角的「？」是可以的）。
- 台词里的 emoji 会先去掉、连续的波浪号合并成一个「～」，文件名按处理后的文本算。
- 如果你用 `lines` 换了台词，语音文件要按**换之后**的台词命名。
- 找不到的台词照旧走内置/缓存/在线合成。「让哈基米出声」关着的话一句都不念。

用 PowerShell 算哈希文件名：
```powershell
$t = "喵？找哈基米有事吗～"
$h = [BitConverter]::ToString([Security.Cryptography.SHA1]::Create().ComputeHash([Text.Encoding]::UTF8.GetBytes($t))).Replace("-","").ToLower()
$h.Substring(0,16)   # → 2b60dc85bb8a2964
```
所有内置台词的原文在仓库的 `assets/voice/lines.json` 里。

## 8. 换台词（lines）

键可以是**一句台词的原文**（只换这一句），也可以是**分类名**（这一类全换）；值是一句或一组（随机挑）。
原文优先于分类。只换固定台词，AI 聊天回复不受影响（那个用 `persona` 管）。

常用分类名（完整列表见 `src/behavior/skin.rs` 的 `CATEGORIES`）：

| 分类 | 场景 | 分类 | 场景 |
|---|---|---|---|
| `hello` | 启动打招呼 | `poke` | 点她 |
| `poke_great` / `poke_sad` / `poke_tired` / `poke_hungry` / `poke_mad` | 不同心情下点她 | `pat` / `shy` / `rub` | 摸头 |
| `feed` / `feed_starving` / `full` | 喂食 | `hungry` / `starving` | 饿了 |
| `drag` / `land_big` / `dizzy` | 被拎/摔/甩 | `sleepy` / `wake` / `wake_up` / `tired` | 睡觉相关 |
| `walk` / `edge` / `sit` | 溜达 | `think` | 发呆 |
| `water` / `stand_up` / `off_work` | 提醒 | `pomo_done` / `pomo_cancel` | 番茄钟 |
| `moyu_on` / `moyu_off` / `moyu_back` | 摸鱼监督 | `peek` / `night` | 叫出来 / 熬夜 |
| `love` / `cry` / `hiss` / `surprised` / `stare` / `yawn` | 各种表情 | `dance` / `song` / `honey` | 跳舞/唱歌/蜂蜜水 |
| `skin_on` | 换成这个角色时说的话，`{name}` 会换成角色名 | | |

带数字的台词（「你走了 3 小时」「番茄钟 25 分钟」之类）目前不能换。

## 9. 打包和分享

1. 确认 `skin.json` 里所有路径都是**相对路径**、只往文件夹里面走（`../` 和 `C:\...` 会被安全导入器直接拦截），且**不要包含任何 `.exe`/`.dll`/脚本代码文件**（仅允许 `json/png/ogg/wav/mp3/flac/txt/md`）。
2. 把整个角色文件夹压成 `.zip`（支持 `我的角色/skin.json` 结构，也支持在压缩包最外层直接放 `skin.json` + `"id": "我的角色"`），总大小不超过 64 MB。
3. 朋友拿到 `.zip` 后：**直接把 `.zip` 拖到桌面上的宠物身上**，或右键「🎭 角色 ▸ 📦 导入角色包 (.zip)…▪」即可一键安装变身。
4. 分享别人画的角色前，记得确认授权。

## 10. 常见问题

- **菜单里没有我的角色**：点「刷新皮肤列表」；还没有就看 `hakimi.log` 里 `skin skipped:` 那几行（多半是 JSON 写错了，或者 skin.json 不在第一层文件夹里）。
- **某个状态还是哈基米**：`sprites` 里状态名拼错了（要全小写，见第 5 节），或者文件名/路径写错、文件不是 PNG。
- **角色太小/太大/飘在空中**：图片下方留白太多 → 裁掉下方空白，或者调 `scale`。
- **聊天还自称哈基米**：在 `persona` 里写清楚「自称××」；清一下聊天记录（设置 → 忘掉聊天记录）效果更好。
- **删了正在用的角色包**：刷新列表后自动回到哈基米；存档里记的名字不变，放回来再刷新就恢复。
