# 第三期 · 新功能实施计划

分支：`feat/phase3`（基于 `fix/stability`，最后与稳定性修复一起合并进 main）。
规则：一步一个提交；每步做完跑 `cargo test --release` + `cargo clippy --release --all-targets -- -D warnings`，
本机重启宠物实测，然后在本文件勾选并写一行结果，再开始下一步。不提交 config.json / 日志 / 任何 Key。

## 第 0 步 · 本机事件接口（地基）
- [ ] 命名管道 `\\.\pipe\hakimi-pet-<user>`，单行 JSON：`{"kind":"done|error|info","source":"...","msg":"..."}`
- [ ] `hakimi-pet.exe --event <kind> [--source x] [--msg "..."]`：有实例在跑就发给它并退出，不起第二只
- [ ] 主循环收到后转成 `AppEvent::External`，行为层先做最小反应（气泡 + 表情）
- [ ] 限流（同源 3 秒内合并）、消息截断 200 字、只接受本机当前用户
- 验收：命令行发三种事件，宠物各有反应；宠物没开时命令安静退出

## 第 1 步 · 跟着我的歌跳（跟实时节拍）
- [ ] 现状：菜单「跟着我的歌跳」+ 音乐检测已有，舞步用内置节拍
- [ ] 用 WASAPI loopback 能量做 onset/BPM 估计，驱动舞步节拍；无声 5 秒自动停
- [ ] 不内置任何音源
- 验收：放两首不同速度的歌，舞步快慢跟着变

## 第 2 步 · 本地模型一键接入
- [ ] 设置里「Ollama（本地）」预设：地址 `http://127.0.0.1:11434`，Key 可空
- [ ] net.rs：localhost / 127.0.0.1 / ::1 / 局域网地址不走代理
- [ ] 「测试连接」按钮：列出已装模型，选一个填进去
- [ ] 本地 TTS：GPT-SoVITS HTTP 接口（用现有参考音频）；固定台词仍用打包语音；不做 Windows 自带声音
- 验收：断网 + Ollama 能正常聊天；GPT-SoVITS 开着时聊天能出声

## 第 3 步 · 对 Claude Code / Codex 做反应
- [ ] 依赖第 0 步
- [ ] 设置页「接入编码助手」：一键把 hook 写进 Claude Code（Stop / Notification）和 Codex（notify）配置；先备份、可撤销
- [ ] 反应：跑完提醒（久跑后夸一句）、出错着急、等你确认时戳你
- 验收：真跑一次 Claude Code 和 Codex，三种反应都出现；撤销后配置还原

## 第 4 步 · Token = 粮食 + 每日花费上限
- [ ] 从接口返回的 usage 计 token；MiMo 按字数计
- [ ] 饱腹度跟用量走：饿 / 正常 / 吃撑（打嗝、拖长尾音）
- [ ] 每日上限（token 或估算金额）：到了先降级到本地模型或固定台词，不直接停
- [ ] 设置页显示今天用量
- 验收：人为调低上限，触发降级和吃撑表现

## 第 5 步 · 每周陪伴报告图
