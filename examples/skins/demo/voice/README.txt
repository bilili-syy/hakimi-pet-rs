这里放这个角色的台词语音（可选）。没有的台词会回退到内置哈基米的声音 / 在线合成。

文件名两种都认：
1. 和内置台词一样的规则：sha1(台词文本) 的前 16 位十六进制 + 扩展名，例如
   「喵？找哈基米有事吗～」 → 2b60dc85bb8a2964.ogg
2. 直接用台词当文件名：喵？找哈基米有事吗～.wav（Windows 文件名不能用的 \ / : * ? " < > | 换成 _）

格式：Vorbis 的 .ogg、.wav、.mp3、.flac（Opus 编码的 .ogg 目前放不出来）。
注意：如果 skin.json 的 lines 把台词换掉了，文件名要按「换掉之后」的台词算。
详见 docs/SKINS.md。
