# 哈基米桌宠 🐱

一只住在 Windows 桌面上的哈基米：会走、会睡、会撒娇，能陪你聊天、用自己的声音说话，还会提醒你喝水、下班和备忘事项。

纯 Rust 编写，单个 exe，约 15 MB，常驻占用很低（60 帧下约一个 CPU 核的 1–2%）。

## 下载

到 [Releases](https://github.com/bilili-syy/hakimi-pet-rs/releases) 下载最新的 `hakimi-pet-vX.Y.Z-windows-x64.exe`，双击运行即可，不用安装。支持 Windows 10 / 11（64 位）。

> 第一次运行时 Windows 可能弹出「已保护你的电脑」，点「更多信息 → 仍要运行」。

## 能做什么

**陪伴**
- 走路、坐下、打哈欠、睡觉、爬到窗口上，拖起来会挣扎，摔下来会发抖
- 27 种表情：开心、委屈、得意叉腰、问号、星星眼、鼓脸生气……随心情和互动变化
- 戳、摸头（滚轮也能撸）、喂小鱼干和蜂蜜水，饥饿、心情、体力会随时间变化
- 换装：水手服、卫衣、睡衣、偶像服、泳装、圣诞裙、女仆装、JK 服，外加圣诞帽、眼镜配件
- 跳舞：内置舞曲、跟着 `songs\` 文件夹里的歌跳，也能实时跟着电脑正在播放的音乐卡点跳

**感知你在做什么**
- 你离开太久会无聊、打哈欠、睡着；回来时星星眼欢迎你
- 打字飞快会给你加油，晃鼠标她会扑过来
- 全屏看视频、打游戏时自动安静并可自动隐藏，退出全屏再回来
- 电脑在放歌时会跟着摇头
- 早安、午饭、深夜提醒，生日和节日问候

**聊天和声音**
- 多行聊天输入框（`Shift+Enter` 换行、`↑/↓` 翻输入历史、`Esc` 中途取消生成），支持导出 Markdown 聊天记录
- AI 支持 Gemini、任意 OpenAI 兼容接口，以及本机 **Ollama**（免 Key、不走代理）；问到新闻天气时会联网搜索
- 语音支持小米 MiMo TTS 与本机 **GPT-SoVITS**（免 Key，默认带哈基米参考录音）；常用台词已内置语音，不联网也能出声
- 用量即口粮：聊天与语音用量会喂饱她，支持设置每日上限（超额自动降级固定台词，不会报错中断）
- 心情会影响语气：开心、困、饿、生气说话都不一样

**小工具**
- 备忘录：聊天里说一句「明天下午三点提醒我开会」就能记下，也能在设置页添加；到点先响叮咚再开口，没确认会再催两次
- 看屏吐槽（默认关闭，开启后按 `Ctrl+Alt+K` 截取当前窗口缩略图，点确认后才发给模型，截图不落盘）
- 每周陪伴报告：生成本周陪伴时长、喂食、聊天与记忆卡片 PNG（自动保存并复制到剪贴板）
- 本机事件通知：`hakimi-pet.exe --event done|error|wait|info [--source 名字] [--msg 内容]`，方便编译脚本或 AI 编码工具回调提醒
- 番茄钟（15 / 25 / 45 分钟）、摸鱼监督、每日签到、天气播报

## 设置

右键哈基米 →「⚙️ 设置…」，或双击托盘图标：

| 页面 | 内容 |
|---|---|
| AI 聊天 | 服务商（含 Ollama 预设）、API Key、模型、每日口粮上限，带「测试连接」 |
| 语音 | MiMo API Key / 本机 GPT-SoVITS 地址、声线模式、念哪些话、音量 |
| 常规 | 大小、帧率（30 / 60 / 120）、开机自启、全屏自动隐藏、看屏吐槽、主人生日、各种提醒 |
| 备忘录 | 查看、添加、完成、删除备忘 |
| 周报 | 预览本周陪伴数据、勾选要放进图里的记忆、一键生成报告图 |

不填 API Key 也能用：走动、互动、换装、跳舞、内置语音、提醒都照常工作，只是不能聊天和合成新台词。

## 数据

全部保存在本机 `%APPDATA%\hakimi-pet\`：

| 文件 | 内容 |
|---|---|
| `config.json` | 设置（含 API Key，请勿分享） |
| `save.json` | 哈基米的状态、等级、换装 |
| `chat.json` / `memory.json` | 聊天记录和记忆 |
| `memo.json` | 备忘录 |
| `tts-cache\` | 合成过的语音缓存 |
| `songs\` | 放自己的歌，跳舞时用 |
| `hakimi.log` | 运行日志 |

## 开发

```
cargo run
cargo test
cargo build --release
```

工具链 `stable-x86_64-pc-windows-gnu`，不需要装 Visual Studio。素材在 `assets/`，编译时直接打进 exe。

主要模块：`src/behavior`（行为和状态机）、`src/render`（tiny-skia 软渲染、分层窗口）、`src/services`（AI、TTS、音频）、`src/platform`（Win32 窗口、菜单、设置页、场景感知）、`src/core`（配置、存档、备忘、记忆）。

调试：设置环境变量 `HAKIMI_TRACE=1` 会在日志里输出帧率、状态切换和语音延迟。
