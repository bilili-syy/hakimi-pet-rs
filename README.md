# 哈基米桌宠 🐱

[![LINUX DO](https://img.shields.io/badge/LINUX%20DO-Community-1F2328?style=flat&logo=discourse&logoColor=white)](https://linux.do)

一只住在 Windows 桌面上的哈基米：会走、会睡、会撒娇，能陪你聊天、用自己的声音说话，还会提醒你喝水、下班和备忘事项。

纯 Rust 编写，单个 exe，约 15 MB，常驻占用很低（60 帧下约一个 CPU 核的 1–2%）。

## 下载

到 [Releases](https://github.com/bilili-syy/hakimi-pet-rs/releases) 下载最新的 `hakimi-pet-vX.Y.Z-windows-x64.exe`，双击运行即可，不用安装。支持 Windows 10 / 11（64 位）。

> 第一次运行时 Windows 可能弹出「已保护你的电脑」，点「更多信息 → 仍要运行」。

## 能做什么

**陪伴**
- 走路、坐下、打哈欠、睡觉、爬到窗口上，拖起来会挣扎，摔下来会发抖
- 32 种表情：开心、眨眼放电、馋得流口水、流汗吐槽、举爪欢呼、犯困点头、委屈鼓嘴、得意叉腰、星星眼……随心情和互动变化
- 戳、摸头（滚轮也能撸）、投喂小鱼干、逗猫棒互动和喝蜂蜜水，饥饿、心情、体力会随时间变化
- 换装与配饰：水手服、卫衣、睡衣、偶像服、泳装、圣诞裙、女仆装、JK 服（多套高频服装含专属生动表情立绘），外加圆眼镜配饰
- 角色包（皮肤）：把 `.zip` 角色包直接拖到桌宠身上即可安全导入变身，每个角色拥有独立的长期记忆、聊天记录与专属声线配置（制作教程见 [docs/SKINS.md](docs/SKINS.md)）
- 跳舞：内置舞曲、跟着 `songs\` 文件夹里的歌跳，也能实时跟着电脑正在播放的音乐卡点跳

**感知你在做什么**
- 你离开太久会无聊、打哈欠、睡着；回来时星星眼欢迎你
- 打字飞快会给你加油，晃鼠标她会扑过来
- 全屏看视频、打游戏时自动安静并可自动隐藏，退出全屏再回来
- 录屏 / 直播隐私保护（默认开启）：检测到 OBS / Streamlabs / B站直播姬 / 抖音直播伴侣运行时，自动禁用看屏吐槽并暂缓主动提起私人记忆与真实生日
- 电脑在放歌时会跟着摇头
- 早安、午饭、深夜提醒，生日和节日问候

**聊天和声音**
- 多行聊天输入框（`Shift+Enter` 换行、`↑/↓` 翻输入历史、`Esc` 中途取消生成），支持导出 Markdown 聊天记录
- 真能动手做事：在聊天里让她换装、戴眼镜、跳舞、唱歌、设提醒、开番茄钟，或打开记事本/计算器/画图及白名单程序（打开外部程序前均会弹出安全确认框）
- AI 支持 Gemini、任意 OpenAI 兼容接口，以及本机 **Ollama**（免 Key、不走代理）；问到新闻天气时会联网搜索
- 语音支持小米 MiMo TTS 与本机 **GPT-SoVITS**（免 Key，默认带哈基米参考录音）；内置近 400 条常用台词录音，不联网也能出声
- 奶油风快捷面板：右键桌宠直接弹出平铺式快捷卡片（8 大常用互动一键直达、10 项衣橱连点试穿不关面板、内嵌双声道音量滑块与角色切换；按住 `Shift + 右键` 或右键系统托盘仍可打开传统完整菜单）
- 独立桌宠音量控制：语音与伴奏双声道分开调节 + 一键总静音；支持快捷面板内直接拖拽、按住 `Ctrl + 滚轮` 在桌宠身上快调，以及聊天口令（「小声点」「静音」）实时生效
- 用量即口粮：聊天与语音用量会喂饱她，支持设置每日上限（超额自动降级固定台词，不会报错中断）
- 心情会影响语气：开心、困、饿、生气说话都不一样

**小工具**
- 备忘录：聊天里说一句「明天下午三点提醒我开会」就能记下，也能在设置页添加；到点先响叮咚再开口，没确认会再催两次
- 看屏吐槽（默认关闭，开启后按 `Ctrl+Alt+K` 截取当前窗口缩略图，点确认后才发给模型，截图不落盘）
- 每周陪伴报告：生成本周陪伴时长、喂食、聊天与记忆卡片 PNG（自动保存并复制到剪贴板）
- 一键接入编码助手：设置「常规」页一键将通知回调无损写入 **Claude Code** 与 **Codex**（自动备份、随时可撤销），也支持任意脚本调用 `hakimi-pet.exe --event done|error|wait|info [--source 名字] [--msg 内容]`
- 番茄钟（15 / 25 / 45 分钟）、摸鱼监督、每日签到、天气播报

## 设置

右键哈基米 →「⚙️ 设置…」，或双击托盘图标：

| 页面 | 内容 |
|---|---|
| AI 聊天 | 服务商（含 Ollama 预设）、API Key、模型、每日口粮上限，带「测试连接」 |
| 语音 | MiMo API Key / 本机 GPT-SoVITS 地址、声线模式、念哪些话、语音与伴奏音量、总静音 |
| 常规 | 大小、帧率（30 / 60 / 120）、开机自启、全屏自动隐藏、看屏吐槽、录屏直播隐私保护、编码助手一键接入、各种提醒 |
| 备忘录 | 查看、添加、完成、删除备忘 |
| 周报 | 预览本周陪伴数据、勾选要放进图里的记忆、一键生成报告图 |

不填 API Key 也能用：走动、互动、换装、跳舞、内置语音、本地短指令、提醒都照常工作，只是不能联网聊天和合成新台词。

## 数据

全部保存在本机 `%APPDATA%\hakimi-pet\`：

| 文件 | 内容 |
|---|---|
| `config.json` | 设置（含 API Key，请勿分享） |
| `save.json` | 哈基米的状态、等级、换装与当前角色 |
| `chat.json` / `memory.json` | 内置哈基米的聊天记录和长期记忆 |
| `skins\` / `skins-data\` | 自定义角色包及其各自独立的记忆与聊天历史 |
| `memo.json` | 备忘录 |
| `tts-cache\` | 合成过的语音缓存 |
| `songs\` | 放自己的歌，跳舞时用 |
| `hakimi.log` | 运行日志 |

## 开发

```
cargo run
cargo test
cargo build --release
```

工具链 `stable-x86_64-pc-windows-gnu`，不需要装 Visual Studio。素材在 `assets/`，编译时直接打进 exe。

主要模块：`src/behavior`（行为和状态机）、`src/render`（tiny-skia 软渲染、分层窗口）、`src/services`（AI、TTS、音频）、`src/platform`（Win32 窗口、菜单、设置页、场景感知）、`src/core`（配置、存档、备忘、记忆）。

调试：设置环境变量 `HAKIMI_TRACE=1` 会在日志里输出帧率、状态切换和语音延迟。
